# Next Word Prediction using Transformer

A deep learning project that predicts the next word in a sentence using a Transformer-based neural network implemented in PyTorch.

---

## Features

- Text preprocessing
- Vocabulary generation
- Tokenization
- Positional Encoding
- Transformer Encoder
- Training and Validation
- Next-word prediction
- Greedy decoding

---

## Tech Stack

- Python
- PyTorch
- NumPy
- Google Colab

---

## Project Workflow

1. Load text corpus
2. Clean and tokenize text
3. Build vocabulary
4. Generate input sequences
5. Train Transformer model
6. Predict next word

---

## Dataset

Custom text corpus uploaded by the user.

You can replace it with any text dataset.
